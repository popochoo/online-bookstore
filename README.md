# 📚 Online Bookstore

Простой интернет-магазин книг с авторизацией, корзиной, динамическими страницами товаров и интеграцией платежной системы. Проект разделен на клиентскую (`client-side`) и серверную (`server-side`) части.

## 🛠 Технологический стек

### Бэкенд (Backend)
* **Фреймворк:** [NestJS](https://nestjs.com) — прогрессивный Node.js фреймворк для создания эффективных и масштабируемых серверных приложений.
* **База данных:** [PostgreSQL](https://postgresql.org) — мощная объектно-реляционная система баз данных.
* **ORM:** [Prisma ORM](https://prisma.io) — современный инструмент для автогенерации запросов, типизации и миграций БД.
* **Авторизация и сессии:** 
  * [Passport.js](http://http://passportjs.org) — гибкая middleware-авторизация для Node.js.
  * `express-session` & `cookie-parser` — менеджмент сессий на стороне сервера.
* **Валидация:** `class-validator` & `class-transformer` (интегрировано через NestJS `ValidationPipe`).
* **Платежный шлюз:** Интеграция с API **ЮKassa** для проведения онлайн-оплаты.

### Фронтенд (Frontend)
* **Фреймворк:** [Next.js](https://nextjs.org) / React.
* **Стилизация:** [SCSS / Sass](https://sass-lang.com) — для гибкой и модульной верстки UI-компонентов.

### Дополнительно
* **Социальная авторизация:** OAuth через Google Client API.
* **Форматирование кода:** Prettier для автоматического поддержания единого стиля кодовой базы.

---

## 🚀 Основной функционал

* **Аутентификация и авторизация:** Классический вход по Email/Паролю, а также быстрая авторизация через сторонний провайдер (Google OAuth).
* **Управление сессиями:** Сессионная авторизация на базе кук, защищающая приватные эндпоинты бэкенда.
* **Управление корзиной:** Логика создания корзины, добавления/удаления книг и изменения их количества.
* **Каталог книг:** Хранение моделей книг в БД, вывод списка товаров и динамический рендеринг персональных страниц для каждой книги.
* **Онлайн-оплата:** Реализован тестовый цикл оплаты заказов через ЮKassa (генерация платежной ссылки, редирект и обработка статуса платежа).

## 💻 Структура проекта

Репозиторий разделен на две независимые директории:
* `/client-side` — фронтенд приложение на Next.js.
* `/server-side` — бэкенд приложение на NestJS.

## 🔧 Запуск проекта локально

### 1. Клонирование репозитория
```bash
git clone https://github.com/popochoo/online-bookstore/
cd online-bookstore
```

### 2. Настройка бэкенда (`server-side`)
Перейдите в папку сервера и создайте файл для переменных окружения:
```bash
cd server-side
touch .env
```
Заполните `.env` актуальными данными для подключения к PostgreSQL (`DATABASE_URL`), секретами сессий, реквизитами Google OAuth (`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`), а также данными тестового магазина ЮKassa (`YUKASSA_SHOP_ID`, `YUKASSA_SECRET_KEY`).

Установите зависимости, примените миграции базы данных и запустите сервер:
```bash
npm install
npx prisma migrate dev
npm run start:dev
```

### 3. Настройка фронтенда (`client-side`)
В новом окне терминала перейдите в папку клиента, установите зависимости и запустите локальный сервер разработки:
```bash
cd client-side
npm install
npm run dev
```

После этого фронтенд будет доступен в браузере по адресу `http://localhost:3000`.
